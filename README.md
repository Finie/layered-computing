# Layered Computing

An interactive study guide for learning computing as a layered abstraction system:
primitive data, memory, data structures, algorithms, application engineering,
distributed systems, cloud infrastructure, and AI systems.

## Local Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run lint
npm run build
```

## GitHub Pages

This project is configured for static GitHub Pages deployment through GitHub
Actions. In the GitHub repository settings, set `Pages` source to
`GitHub Actions`.
